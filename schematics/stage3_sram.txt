STAGE 3 - SRAM  (HY62CT08081E-D70C, 32K x 8, DIP-28)  ->  RAM at $0000-$7FFF
===============================================================================

No new logic chips: the 74LS00 (U4) already makes every control signal the SRAM needs.
Everything else stays exactly as in stage 2 (full_pinmap.txt).

If you tied SRAM pin 20 (/CS) to +5V earlier, REMOVE that wire; it now goes to A15.

Pinout (standard 62256 layout; check yours matches: pin 1 = A14, pin 28 = VCC):

                    +----\/----+
          A14   1 --|          |-- 28  VCC
          A12   2 --|          |-- 27  /WE
          A7    3 --|          |-- 26  A13
          A6    4 --|          |-- 25  A8
          A5    5 --|          |-- 24  A9
          A4    6 --|          |-- 23  A11
          A3    7 --|  HY62C   |-- 22  /OE
          A2    8 --|          |-- 21  A10
          A1    9 --|          |-- 20  /CS
          A0   10 --|          |-- 19  D7
          D0   11 --|          |-- 18  D6
          D1   12 --|          |-- 17  D5
          D2   13 --|          |-- 16  D4

It is almost the same as the 28C64: same address/data pins on 2-25, except
pin 1 = A14 (EEPROM: RDY/BUSY), pin 26 = A13 (EEPROM: NC), and pins 20/22/27 differ.

Easiest way on a breadboard: put the SRAM next to the EEPROM and run each
address/data wire from the EEPROM pin to the matching SRAM pin (same pin number
for pins 2-13 and 15-25), then add the 6 different ones: 1, 20, 22, 26, 27, 28/14.


HOW IT IS SELECTED
------------------
  /CS = A15         -> SRAM is on for $0000-$7FFF (A15 = 0), off for $8000-$FFFF
  /OE = WR          -> SRAM drives the bus only on read cycles
  /WE = /WSTB       -> SRAM writes only during the second half (phi2) of a write cycle
No conflict with the EEPROM: the EEPROM is only on for $C000-$FFFF (A15 = 1).
